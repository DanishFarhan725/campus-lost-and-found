A good report is specific

  • Name it plainly. “Grey Casio calculator”, not “calculator”.
  • Pin down the place. Building, floor and room help the most.
  • Mention what’s unique. Stickers, scratches, a name written inside.
  • Found an ID card? Leave out the ID number so only the owner can confirm it.
